# Weather Dashboard

A Python project for learning software development by building a real-world weather analytics application.

## Project Goal

The goal of this project is to gain hands-on experience with:

* Python development
* Working with APIs
* Handling JSON data
* Git and GitHub workflows
* Project architecture and clean code practices
* Data storage and analysis
* Data visualization

Rather than following tutorials, this project is being built incrementally through planning, implementation, testing, and refactoring.

## Current Status

## Setup

Clone the repository:

```bash
git clone <repository-url>
cd weather_dashboard
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment:

```bash
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```
